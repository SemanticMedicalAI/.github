# SemanticMedicalAI

Research organization focused on semantic medical NLP, ontology generation, graph reasoning and AI-assisted clinical reasoning systems.

---

# Vision

SemanticMedicalAI aims to build modular and scientifically grounded frameworks for transforming unstructured clinical data into semantically interpretable knowledge structures suitable for:

- clinical NLP
- ontology generation
- semantic reasoning
- graph-based AI systems
- explainable medical AI
- LLM-supported clinical assistance

The long-term goal is the development of transparent and semantically structured medical AI pipelines capable of supporting interpretable and evidence-linked clinical reasoning.

# Architecture Overview

The overall framework follows a modular architecture:

```text
Raw Clinical Documents
        ↓
Preprocessing & Structuring
        ↓
Semantic Extraction
        ↓
Ontology Generation
        ↓
Knowledge Graph Construction
        ↓
Graph Reasoning
        ↓
LLM-assisted Clinical Interpretation
```

---

# Repository Overview

| Repository | Purpose |
|---|---|
| `PreprocessingLLMHealth` | Medical preprocessing pipeline for pseudonym verification, semantic parsing and structured JSON generation |
| `OntologyBuilder` | Automatic ontology and semantic concept generation from medical text |
| `GraphReasoning` | Graph construction, traversal, semantic linking and reasoning |
| `SemanticMedicalAI-POC` | End-to-end proof of concept integrating preprocessing, graph structures, LLMs and frontend systems |
| `EvaluationFramework` | Evaluation, benchmarking and validation of semantic extraction and reasoning pipelines |
